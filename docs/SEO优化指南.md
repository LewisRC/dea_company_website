## 📈 百度站长平台配置

### 1. 站点验证
- ✅ 已完成文件验证

### 2. 提交sitemap
1. 登录百度站长平台
2. 进入"数据引入" → "链接提交"
3. 提交sitemap地址：`https://www.dsakj.com/sitemap.xml`

### 3. 主动推送（可选）
如需使用主动推送API：

1. 在百度站长平台获取推送token
2. 在服务器上创建 `.env.local` 文件：
```bash
BAIDU_PUSH_TOKEN=your_token_here
```

3. 运行推送脚本：
```bash
node scripts/push-to-baidu.js
```
